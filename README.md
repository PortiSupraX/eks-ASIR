# eks-ASIR
Crear y gestionar un clúster de Kubernetes utilizando un servicio gestionado en la nube (EKS, AKS o GKE), desplegar una aplicación web en contenedores y exponerla a Internet mediante un balanceador de carga. Finalmente, escalar la aplicación para comprobar cómo Kubernetes gestiona la carga en un entorno cloud.
